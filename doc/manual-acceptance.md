# 人工验收说明

所有用例目前均为 `manual_pending`。请仅在明确提供的测试 Zotero Profile 中安装插件，并先在“AI 精读设置”填写 Webhook URL 与 Token。

1. 文本型 PDF：选择一篇有可检索文本 PDF 的普通论文，确认显示读取全文、发送、等待，并显示返回路径或文件名。
2. 仅摘要：选择无 PDF 但有摘要的普通论文，确认显示“正在使用摘要”且请求成功。
3. 扫描 PDF 降级：选择扫描型 PDF 且有摘要的论文，确认使用摘要而非上传 PDF。
4. 无可分析内容：选择 PDF 与摘要均无内容的论文，确认显示无内容错误且不调用 Webhook。
5. 多选：同时选择多篇文献，确认提示第一版仅支持一篇且不调用 Webhook。
6. Token 为空或错误：分别留空和填写错误 Token，确认提示配置/鉴权错误且不自动重试。
7. n8n 不可达：停止测试 n8n 服务或使用不可达测试 URL，确认提示检查 n8n 与 URL。
8. n8n 业务错误：使测试 Webhook 返回 `success: false`，确认展示其简短 message。
9. 重复点击：同一条目快速触发两次，确认第二次提示正在处理中，且仅有一次请求。
10. 成功写入磁盘并返回路径：使用现有测试 Webhook，确认成功提示包含 `relativePath` 或 `filename`；插件本身不创建 Zotero 笔记、不写入 Obsidian。
